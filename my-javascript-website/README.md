first class was about github
start by creating a github repository if you don't have one
clone the repository to your machine using cmd
use the command "git clone https://github.com/Rachelgit4/bootcamp.git" you only clone once
use the command cd to change directory
use the command "code ." to open your directory on vs code
after doing changes push your work to github
use the command "git add ." as the first step to add you work to github
use the command "git commit -m " commit message" " to commit your work to github. The commit message helps us know what kind of change was done previously
the last step is to push your work to github using the command "git push"
